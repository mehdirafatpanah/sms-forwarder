# ShopVPN SMS Forwarder

اپ اندروید مینیمال برای فوروارد کردن پیامک‌های واریزی بانک به وب‌هوک سرور ShopVPN
(برای سیستم تایید خودکار رسید بانکی).

## نکته مهم درباره انتشار
این اپ به‌خاطر مجوزهای `RECEIVE_SMS` و `READ_SMS` **نمی‌تواند در Google Play منتشر شود**
(پلی‌استور این مجوزها را فقط به اپ پیش‌فرض پیامک‌رسان می‌دهد). این اپ برای **نصب مستقیم (sideload)**
روی گوشی خودت یا هر گوشی دیگری که برای این کار اختصاص می‌دهی طراحی شده — دقیقاً مثل Tasker/Macrodroid.

## نحوه ساخت (Build)
1. پوشه `BankSmsForwarder` را با Android Studio (نسخه Hedgehog به بعد) باز کن.
2. Android Studio هنگام باز شدن، Gradle Wrapper را خودش دانلود و sync می‌کند
   (چون فایل باینری `gradle-wrapper.jar` در این پکیج قرار داده نشده).
3. از منوی Build > Generate Signed Bundle/APK یک APK بساز، یا مستقیم روی گوشی متصل Run بگیر.

## نحوه استفاده
1. اپ را نصب کن، مجوز خواندن پیامک را با دکمه بالای صفحه فعال کن.
2. روی گوشی، «بهینه‌سازی باتری» را برای این اپ خاموش کن (دکمه دوم) تا اندروید در پس‌زمینه
   اپ را نکشد و پیامک‌ها با تاخیر/از دست نروند. در گوشی‌های شیائومی/هواوی/سامسونگ معمولاً
   یک تنظیم اضافه به نام «Autostart» یا «اجرای خودکار» هم باید از تنظیمات گوشی روشن شود.
3. آدرس وب‌هوک سرور و توکن امنیتی (که در بخش سرور پروژه ساخته می‌شود) را وارد و ذخیره کن.
4. اختیاری: شماره فرستنده‌های بانک‌ها را با کاما وارد کن تا فقط پیامک‌های بانکی فوروارد شوند
   (اگر خالی بگذاری، همه‌ی پیامک‌های گوشی فوروارد می‌شوند — توصیه نمی‌شود).
5. با دکمه «ارسال پیام آزمایشی» اتصال به سرور را تست کن.

## قالب داده‌ای که به سرور فرستاده می‌شود
هر پیامک به شکل زیر با متد POST و هدر `X-Webhook-Token` ارسال می‌شود:

```json
{
  "sender": "50004343",
  "body": "متن کامل پیامک بانک",
  "received_at": 1717000000000,
  "device_id": "device-xxxxx"
}
```

`received_at` میلی‌ثانیه یونیکس‌تایم است. `device_id` یک شناسه محلی و ثابت برای هر نصب اپ است
(در صورت داشتن چند گوشی برای چند بانک، برای تشخیص منبع مفید است).

## معماری داخلی (خلاصه)
- `SmsReceiver`: با اولویت بالا `android.provider.Telephony.SMS_RECEIVED` را می‌گیرد،
  بر اساس لیست سفید شماره‌ها فیلتر می‌کند و کار شبکه را به WorkManager می‌سپارد.
- `ForwardWorker`: ارسال HTTP با OkHttp؛ در صورت قطعی شبکه یا خطای ۵xx سرور،
  با backoff نمایی خودش را retry می‌کند (این‌طوری اگر گوشی موقتاً آفلاین باشد، پیامک گم نمی‌شود).
- `Prefs` / `LogStore`: تنظیمات و لاگ فعالیت اخیر، محلی روی گوشی ذخیره می‌شوند.

## قدم بعدی
بخش سرور (جدول دیتابیس، پارسر پیامک بانک‌ها، اندپوینت وب‌هوک و پنل ادمین) در فاز بعدی
پیاده‌سازی می‌شود.
